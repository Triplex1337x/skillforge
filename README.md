# SKILLFORGE

Русскоязычная платформа персональной игровой аналитики и тренировок. Next.js App Router, TypeScript, Tailwind CSS, компоненты в стиле shadcn/ui на Radix UI и Recharts. Данные хранятся в localStorage текущего браузера.

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Для проверок используйте `npm run typecheck` и `npm run build`. Собранный сервер запускается командой `npm start`.

## Работа с данными

Новый профиль открывается с личной статистикой. Обозначенный деморежим можно включить в настройках. Ссылка «К моим матчам» или сохранение личного матча возвращают личный набор данных. Демоматчи не редактируются. Достижения учитывают только личные матчи и выполненные упражнения. В настройках можно скачать локальные записи и профиль в JSON.

История, графики и упражнения зависят от выбранной игры. Поля метрик необязательны. Пустые значения исключаются из средних, ноль учитывается. Процент побед равен числу побед, делённому на число матчей, включая ничьи. Рейтинг в каталоге игр использует все матчи выбранного набора. Обзор и аналитика используют выбранный период. На графике точка рейтинга рассчитана по окну до десяти матчей внутри периода.

## Рейтинг мастерства

Шкала 0–1000 применяется отдельно к каждой игре:

- 75% оценки составляет среднее отношений «среднее значение метрики / ориентир». Каждое отношение ограничено единицей.
- 25% оценки составляет средний результат матчей: победа — 1, ничья — 0,5, поражение — 0.
- Для рейтинга нужен хотя бы один матч с заполненной метрикой. Ориентиры являются настройками приложения. Шкала отражает личный прогресс и не является официальным рангом либо турнирным рейтингом.

## Архитектура

- `lib/games.ts` задаёт контракт `GameAdapter` и реестр. Для добавления игры внесите уникальный идентификатор, роли, метрики с ориентирами и упражнения. Форма, каталог и аналитика используют реестр.
- `lib/data.ts` содержит модель, расчёты и асинхронный контракт `Repository`. Чтобы перейти на Supabase, добавьте реализацию этого контракта с авторизацией и политиками доступа по владельцу. При переходе от локальных снимков к одновременному редактированию с нескольких устройств стоит реализовать операции по отдельным сущностям и контроль конфликтов. Supabase сейчас не подключён.
- `CoachProvider` отделяет правила рекомендаций от интерфейса. Текущий тренер сравнивает метрики с ориентирами игры и проверяет процент побед. Сетевые вызовы и платные API отсутствуют.


## Трансляции Twitch

Вкладка «Трансляции» содержит каналы организаторов и ссылки на категории всех 11 игр. На HTTPS и localhost встроенный плеер получает состояние эфира от Twitch после запуска. При открытии по локальному HTTP-адресу или если ширина плеера меньше 400 px эфир открывается на Twitch. Наличие прямого эфира зависит от расписания каналов. Ключи Twitch API не нужны.

## Открытие с телефона

Подключите телефон и компьютер к одной сети. Соберите приложение и оставьте сервер запущенным:

```bash
npm run build
npm start -- --hostname 0.0.0.0
```

На телефоне откройте `http://IP-КОМПЬЮТЕРА:3000` (локальный IPv4 можно узнать командой `ipconfig` в Windows). Матчи хранятся отдельно в каждом браузере и для каждого адреса. Записи на ПК и телефоне автоматически не синхронизируются.

## Локальные профили и достижения

При первом запуске создаётся профиль, после подтверждения пароля выбирается игра. Логины, проверочные значения паролей и данные профилей разделены в localStorage. Для проверки используется PBKDF2-SHA256 с уникальной солью. Старые записи в данном браузере сохраняются в первом зарегистрированном профиле. Это локальный режим. Для общей учётной записи на разных устройствах потребуется серверная авторизация.

У каждой дисциплины шесть достижений, включая три цели по её метрикам. Они показаны в отдельном разделе и в профиле. Смерти и дополнительные счётчики с отключённым вкладом в рейтинг отображаются в статистике, но не меняют формулу оценки.

## Идея для подписки

Распознавание итогового экрана по фото или скриншоту. Предлагаемый сценарий — выбрать игру, загрузить изображение, сверить распознанные поля и подтвердить запись. Для реализации понадобятся проверка качества по играм и обработка неопределённых полей. Подписка, распознавание и оплата ещё не подключены.


## Публикация на GitHub Pages

Создайте публичный репозиторий и выберите **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает и публикует сайт после отправки изменений в `main`. Путь проекта определяется настройками Pages, поэтому сборка работает и в подпапке репозитория.

Профили и история матчей хранятся в браузере. Опубликованный HTTPS-адрес имеет отдельное хранилище, поэтому данные с локального адреса в нём автоматически не появляются.
